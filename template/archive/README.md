# Archive

Superseded canonical content, moved here by the curator instead of deleted
— e.g. a past decision that was later reversed, or a topic file split/
restructured where the old shape still has standalone historical value.
See `../CURATOR.md`'s UPDATE and restructuring guidance.

Not a trash can: only content with genuine standalone value to keep around
lands here. Anything with no reusable value is discarded outright (and
still logged in `../CURATION-LOG.md`, per the curator's no-silent-deletes
rule) rather than archived.

This folder has no required structure — mirror the original path under
`../memories/` if that's convenient, or keep it flat. Whatever's easiest to
find later.
